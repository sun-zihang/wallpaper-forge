常见问题

TEX 文件是什么？

TEX 是 Wallpaper Engine 使用的纹理容器，内部通常封装 PNG 或压缩纹理数据，浏览器与普通看图软件无法直接打开。

转成 PNG 会有画质损失吗？

不会。这是解包提取而非重新编码：像素原样写入无损的 PNG 文件。

文件会上传吗？

不会。容器解析与 PNG 写出全部在本机浏览器完成，文件不离开你的电脑。

包在 pkg / mpkg 里的 tex 也能转吗？

可以。用同一个工具打开 .pkg / .mpkg，其中的 .tex 会出现在文件树里，可直接预览并转出 PNG。
