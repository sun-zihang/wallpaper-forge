常见问题

GIF 转 PNG 需要注册吗？

不需要。打开工具直接用，没有账号体系、没有广告、没有次数限制。

文件会上传到服务器吗？

不会。解析、渲染、打包全部发生在你的浏览器进程里，网络请求只用于加载页面与开源依赖库。

支持多大的 GIF？

Web 版单文件 100MB 以内；总像素过高的动图会在开始前被拦截并提示改用桌面版，避免浏览器内存崩溃。

提取出来的 PNG 会压缩画质吗？

不会。PNG 是无损格式，逐帧提取保留原始像素；只有在你主动选择 JPG 等有损格式时才会重新编码。
