What it does

  • Extract every GIF frame as a complete, lossless PNG bitmap;
  • Apply a frame stride (keep every Nth frame) so you only export the frames you need;
  • Process multiple GIFs at once with per-file progress, then download everything as one ZIP;
  • The reverse direction too: merge still images back into an animated GIF in the same tool;
  • Drag finished frames straight into a local folder (Chrome / Edge).

Three steps to convert

  1. Open the tool and drop GIF files into the file area — or click to choose files.
  2. Pick the split mode and frame stride, press Start, and follow each file's progress.
  3. Download the results as a ZIP, or drag single frames out to save them locally.

Why convert in the browser

The engine (gifuct parsing + Canvas rendering) runs right inside the page. With no upload step there is no server queue and no privacy concern. No account, no sign-in — open the tab and work; when you close it, your data stays on your machine.

Files over 100MB or animations with thousands of frames? The desktop version has no size limit, adds GPU acceleration, and exports directly to Wallpaper Engine.

FAQ

Do I need an account to convert GIF to PNG?

No. Open the tool and start converting — no accounts, no ads, no usage caps.

Are my files uploaded to a server?

No. Parsing, rendering and packaging all happen inside your browser process; network requests only load the page and its open-source dependencies.

How large a GIF can I convert?

Up to 100MB per file in the web version. Animations with an extreme total pixel count are blocked before they start, with a clear suggestion to switch to the desktop version.

Will the extracted PNGs lose quality?

No. PNG is lossless, so frame-by-frame extraction preserves the original pixels. Re-encoding only happens if you actively pick a lossy format such as JPG.
