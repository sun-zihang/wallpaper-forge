Why this tool exists

Workshop wallpapers wrap their assets in .tex for faster loading, which regular image viewers can't open. This tool cracks the container and lifts the pixels out untouched, so you can inspect and reuse the textures — all inside your browser, with the assets never passing through any server.

FAQ

What is a TEX file?

TEX is the texture container Wallpaper Engine uses. It usually wraps PNG or compressed texture data that browsers and normal image viewers cannot open.

Does converting to PNG lose quality?

No. This is extraction rather than re-encoding: pixels are written into a lossless PNG file exactly as they were.

Are my files uploaded?

No. Parsing the container and writing the PNG both happen in your local browser; files never leave your computer.

Can I convert TEX packed inside pkg / mpkg?

Yes. Open the .pkg / .mpkg with the same tool — its .tex files appear in the file tree, ready to preview and export to PNG.
