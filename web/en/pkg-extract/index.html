What it does

  • Parse .pkg / .mpkg packages, list every file inside and build a browsable directory tree;
  • Preview key assets in place — images and .tex textures render directly, no extraction needed first;
  • Extract multiple packages at once with per-file progress;
  • Download the whole extraction as a ZIP, or save it into a local folder;
  • Unsupported variants get an explicit "use the desktop version" message instead of failing silently.

Three steps to unpack

  1. Open the tool and drop .pkg / .mpkg files into the file area.
  2. Press Start and let it parse — an asset info card and the file tree appear on the right.
  3. Browse and preview the contents in the tree, then download everything as a ZIP.

Why unpack in the browser

Package parsing is pure local computation, so the browser is both fast and safe: there is no upload step, and Workshop assets never pass through any third-party server. You are simply reading a file into your own machine to see what is inside.

Need batch extraction, direct import back into Wallpaper Engine, or more variants? The desktop version supports one-click WE import and batch jobs.

FAQ

Do I need Wallpaper Engine installed?

No. The parser runs in your browser, so any .pkg / .mpkg file can be read directly.

Are my files uploaded?

No. Reading the package and building the directory tree both happen on your machine; files never leave your computer.

Which formats are supported?

.pkg and .mpkg project packages plus .tex textures — and .tex can be converted to PNG in the TEX to PNG tool.

Can I reuse the assets in WE?

Images and videos can be viewed and reused directly. To send processed results back into Wallpaper Engine in one click, the desktop version provides import.
