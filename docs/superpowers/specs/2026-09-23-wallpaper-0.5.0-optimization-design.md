# Wallpaper Converter 0.5.0 — 瘦身 / 大任务 / 稳定性 / 细节优化

日期：2026-09-23  
范围：A 体积瘦身 + B 大任务体验 + C 稳定性 + 细节修复；一次做完，升版 0.5.0 并发布。

## 背景与目标

当前 0.4.0 安装包约 115MB，解包 `dist/` 约 431MB。主要死重量：

- 同一份 ffmpeg 打进两份：`vendor/ffmpeg/ffmpeg.exe`（spec 主动拷贝）+ `imageio_ffmpeg/binaries/*`（依赖被静态收集）
- `cv2/opencv_videoio_ffmpeg500_64.dll`（约 29MB，去水印只用 imread/inpaint/imwrite，视频走独立 ffmpeg）
- 无用 Qt 栈：`opengl32sw.dll`、`Qt6Quick`/`Qt6Qml`/`Qt6Pdf` 等（纯 QtWidgets 应用）

体验问题：图片/GIF 大批量取消无效；视频进度条不动；关窗不等任务；取消 ffmpeg 留半截文件；错误只显示「FFmpeg 编码失败」看不到 stderr；设置页 `default_quality`/`default_gif_fps` 存了没生效；裁剪/框选对话框全分辨率 pixmap 拖拽卡。

**成功标准**

| 项 | 目标 |
|----|------|
| `dist` 解包 | < 280MB（力争） |
| Setup | < 80MB（力争） |
| 测试 | 全绿；新增 cancel/progress/settings 用例 |
| 冒烟 | 6 页可开、视频/去水印仍可用 |
| 取消 | 1000 文件批量按取消立即停 |
| 进度 | 视频转换进度条按百分比走 |
| 关窗 | 有任务先提示再退出 |

## 方案分节

### A. 瘦身（build + 依赖）

1. `requirements.txt`：移除 `imageio-ffmpeg`（或仅注释为开发可选，不进 runtime 依赖）。
2. `core/ffmpeg_finder.py`：去掉对 `imageio_ffmpeg` 的运行时回退（或冻结环境永不调用）；查找顺序保持：exe 目录 → `_internal/` → `WALLPAPER_FORGE_FFMPEG` → `vendor/ffmpeg/` → `PATH`。
3. `build/app.spec`：
   - 过滤 `a.binaries`/`a.datas`：丢弃路径含 `imageio_ffmpeg`、`opencv_videoio_ffmpeg`、`opengl32sw`、`Qt6Quick`、`Qt6Qml`、`Qt6Pdf`、`Qt6OpenGL` 的项（名称按实际收集结果微调）。
   - `Analysis(excludes=...)` 增加上述 Qt 子模块（若 hidden import 拉入）。
4. 打包后核对 `dist` 体积与 `_internal/ffmpeg.exe` 仍在；`ffmpeg_available()` 为真。

不改业务代码路径逻辑；若 imageio 回退删除影响测试，更新 `tests/test_ffmpeg_finder.py`。

### B. 大任务体验

1. **可取消**
   - `gui/workers.py` `execute_task`：图片转换、GIF split/merge、unpack tex 等 per-file 循环内检查 `cancel_event.is_set()` 则 `raise`/`return` 已取消语义（沿用现有「已取消」字符串约定）。
   - `core/gif_ops.py` 拆帧循环接收可选 `cancel_event`。
2. **真实进度**
   - `core/video_ops.py` `run_ffmpeg`：增加可选 `progress_cb(pct:int|None)`；优先 `-progress pipe:1` 解析 `out_time_ms`/`duration` 得百分比，或解析 stderr `time=`；duration 可用 `-i` 解析或省略时只发 indeterminate。
   - `TaskRunner` 增加 `progress_pct = Signal(int)`；`execute_task` 经 `params` 里传入回调或 runner 引用。
   - `BasePage` 连接 `progress_pct` 更新 `self.progress`；任务级 `progress(i,total)` 仍保留作状态栏。
3. **列表性能**
   - `gui/widgets/file_table.py`：插入时 `setUpdatesEnabled(False/True)`；维护 `self._row_index: dict[Path, int]`，`set_status_for_path` O(1)；增删清空时重建。
   - 文件夹扫描可仍在 UI 线程但批量插入（本轮不引入后台扫描，避免拖拽复杂度）。
4. **UI 线程不阻塞**
   - 删除 `probe_video_size` 中第一次无用的 ffprobe 风格 subprocess（只保留一次 `ffmpeg -i` 解析）。
   - `RewatermarkPage.start_batch`：分辨率探测挪到任务执行时（`REMOVE_VIDEO_WATERMARK` params 在 worker 内解析，或仅在 worker 线程 probe）；`extract_preview_frame` 保持在点击「框选」时（短操作），可接受。

### C. 稳定性

1. **关窗**：`MainWindow.closeEvent` — 若任一 `BatchThread.isRunning()`，弹确认；确认则对各页 `thread.cancel()` + `wait(3000)`，再关。
2. **半截文件**：`run_ffmpeg` 取消/失败路径删除已写入的 `dst`（若本次创建）。
3. **错误详情**：`VideoOpError` 已有 `stderr_tail`；`friendly_error` 若 `str(e)` 为空或过短，附加 `getattr(e,'stderr_tail','')` 截断至 ~200 字符；`FileTable` 失败状态用 tooltip 或状态列展示完整短详情。

### 细节

1. **设置生效**：`ImagePage`/`VideoPage`/`GifPage`（及 unpack 每 N 秒若有对应设置）在 `apply_settings` 中写入 `default_quality`、`default_gif_fps` 到现有控件；`SettingsPage` 保存逻辑不变。
2. **框选流畅**：`gui/dialogs.py`、`gui/dialogs_boxselect.py` 打开时将原图缩到对话框可用尺寸一次缓存 `_display_pix`；拖拽中用 `FastTransformation` 或直接画缓存；仅「确定」前不需要原图全采样。
3. **完成提示**：`BasePage._on_batch_done` — 取消导致 failed>0 且 ok==0 时不弹「批量完成」成功框，只状态栏写「已取消」；有成功仍弹简短结果。

## 架构与边界

- 瘦身只动 `build/app.spec`、`requirements.txt`、`ffmpeg_finder`；不碰任务模型。
- 取消/进度只动 `workers`、`video_ops`/`gif_ops`、`base`/`file_table`；`core` 保持无 Qt。
- 关窗只动 `main_window`。
- 不新增功能页；不改输出路径规则；不改自动更新逻辑（镜像直链已做）。

## 错误处理

- 取消沿用 `已取消` / `UpdateError` 风格；ffmpeg 失败仍映射中文 `视频处理失败` + stderr 摘要。
- 关窗取消超时（wait 3s 未结束）则提示「仍有任务未结束，强制退出可能产生半截文件」再允许关闭或取消关闭（选：再次确认强制关）。
