# Wallpaper Converter 网页版 — Cloudflare Pages（方案 A：纯静态 + 浏览器内处理）

日期：2026-09-23  
状态：设计已批准（方案 A）；待实现计划。  
关联：桌面版 0.5.0 已发布；本 spec 不改桌面业务架构。

## 目标与边界

| | 网页版（Cloudflare Pages） | 桌面 0.5.x+ |
|--|--|--|
| 部署 | Push → Pages 自动构建，静态资源 | 安装包 + GitHub Release |
| 图片转换 / 裁剪 / 水印 | ✅ 浏览器内 | ✅ |
| GIF 拆帧 / 合帧 | ✅ | ✅ |
| 视频互转 / 转 GIF / 截帧 / 片段截取 | ✅ ffmpeg.wasm（有上限） | ✅ 本机 ffmpeg，无上限 |
| WE 解包（.pkg / .tex / .mpkg） | ✅ JS 移植 | ✅ |
| 去水印 | ❌ 按钮 → 引导下载桌面版 | ✅ |
| 自动更新 / 国内镜像直链 | 不适用（Pages 即发布） | 保留 |

**成功标准**

| 项 | 目标 |
|----|------|
| 部署 | 仓库 push 后 Pages 可访问 HTTPS 首页 |
| 图片 | 互转、质量/缩放、裁剪、文字/图片水印与桌面语义一致（同夹具同结果类别） |
| GIF | 拆帧步长、合帧间隔/循环/倒放可用 |
| 视频 | 按需加载 wasm；进度 0–100；超限明确提示用桌面版 |
| 解包 | 至少覆盖桌面测试已覆盖的样例格式；不支持变体中文报错 |
| 隐私 | 无上传服务器；文件仅在浏览器内存/下载 |
| 桌面回归 | 现有 pytest 仍全绿 |

**明确不做**

- Cloudflare Workers / Durable Objects / R2 服务端转码  
- 用户账号、云端存储、服务端去水印  
- 仓库内提交 ffmpeg.wasm 大二进制（外链 CDN）  
- 桌面与网页共享同一运行时代码（只共享算法语义与测试向量）

## 方案选型（已批准）

- **A（采用）**：纯静态 Pages + 浏览器内处理。  
- **B（否决）**：Pages + Workers 远程重活 —— Workers 无 ffmpeg 二进制，CPU 时间与长视频不匹配，成本复杂度高。  
- **C（否决）**：WebView2 桌面壳 —— 不是 Cloudflare 部署目标。

## 架构

```
wallpaper-forge/
├── core/ gui/ tests/ …     # 现有桌面（本 spec 不改业务）
├── web/                    # 新：网页版根
│   ├── index.html          # 单页壳
│   ├── app.js              # 简易路由 / 全局状态 / 任务列表
│   ├── styles.css
│   ├── pages/
│   │   ├── home.js         # 四宫格 + 去水印引导卡片
│   │   ├── image.js        # 转换 / 裁剪 / 水印
│   │   ├── gif.js          # 拆帧 / 合帧
│   │   ├── video.js        # 四模式 + wasm 生命周期
│   │   └── unpack.js       # pkg / tex / mpkg
│   ├── lib/
│   │   ├── image_ops.js    # 对照 core/image_ops + annotate
│   │   ├── gif_ops.js      # 对照 core/gif_ops
│   │   ├── we_pkg.js
│   │   ├── we_tex.js
│   │   ├── we_mpkg.js
│   │   ├── video_bridge.js # 加载/调用/取消/进度 封装
│   │   ├── errors.js       # friendly_error 中文映射
│   │   └── download.js     # 单文件 Blob 下载 + JSZip 批量
│   └── tests/              # 与 core 对照的夹具用例
├── docs/superpowers/…
└── (Cloudflare Pages)      # build output = 仓库静态根或 web/ + 配置
```

- **模块**：原生 ES modules，不引入打包器（除非实现计划中确认需要）。  
- **ffmpeg.wasm**：运行时 `import()` / 动态 script，源用 jsDelivr 或 unpkg；版本钉死在实现计划中写死。  
- **JSZip**（或等价）：CDN 引入，用于解包与批量下载。  
- **与桌面关系**：两套 UI；`web/lib/*` 对照 `core/*` 移植，**测试向量**（小样本输入与期望属性）两边共用约定，不共享 Python/JS 运行时。

## 页面与交互

单页多视图（hash 或 history 路由均可，实现计划二选一）：

1. **首页**  
   - 功能入口：图片、GIF、视频、解包。  
   - 「去水印 → 桌面版」卡片：链接到 Releases / README 下载表。  
   - 隐私说明：文件不离开本机。

2. **图片**  
   - 多选/拖拽；格式 PNG/JPG/WebP/BMP/GIF、质量、可选等比缩放到宽度。  
   - 裁剪：预览上框选（语义对齐桌面 `CropDialog`）。  
   - 水印：文字（字号/透明度/位置）与图片（缩放/透明度/位置）。  
   - 批量：列表状态列（等待/处理中/完成/失败/已取消），可取消。

3. **GIF**  
   - 拆帧：步长 ≥1 → 输出 PNG 序列 zip。  
   - 合帧：帧间隔、循环、倒放 → 单个 GIF 下载。

4. **视频**  
   - 模式：格式互转、转 GIF、截帧、片段截取（与桌面一致）。  
   - 引擎：进入页或首次开始时按需加载 wasm；加载中禁用开始按钮并显示进度文案。  
   - 进度条：0–100，与桌面 `progress_pct` 同语义。  
   - 上限：默认单文件 **≤100MB** 且 **≤5 分钟**（常量，可调）；超限提示使用桌面版。  
   - 取消：中止当前 ffmpeg 调用，任务标「已取消」，删除中间产物。

5. **解包**  
   - 拖入 `.pkg` / `.tex` / `.mpkg` → 识别类型 → 产物列表 → zip 下载。  
   - 不支持子格式：中文错误说明「该变体请用桌面版」，不静默失败。

**输出**：一律浏览器下载；无服务端写入。

## 错误处理

- `lib/errors.js`：集中映射为中文短句（对齐桌面 `friendly_error` 风格）。  
- 视频失败：附带 ffmpeg 输出尾部摘要（截断约 200 字符）。  
- 取消统一文案「已取消」。  
- 选文件阶段拦截：错误扩展名、超上限、空文件 —— 不进入任务队列。

## 错误处理与风险

| 风险 | 缓解 |
|------|------|
| ffmpeg.wasm 体积/慢 | 按需加载；上限拦截；文案引导桌面 |
| WE 格式覆盖不全 | 对照桌面测试夹具；不支持即显式中文错误 |
| 浏览器内存（大图/长 GIF） | 分文件串行处理；失败不中断整批 |
| CDN 不可达 | 钉死版本 + 实现计划中准备备用镜像列表（若需要） |
